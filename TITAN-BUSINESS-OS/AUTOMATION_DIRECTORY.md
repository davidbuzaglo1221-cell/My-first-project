# אוטומציות

אין עדיין אוטומציות פעילות. כל אוטומציה שפונה לאנשים אמיתיים (הודעות, פרסום) דורשת אישור של דוד על הטון ועל מה מותר לה לעשות לבד.

## מתוכנן
| אוטומציה | כלי | תנאי |
|---|---|---|
| מענה להודעות אינסטגרם | Meta Graph API + סוכן | חשבון עסקי + אישור טון וגבולות |
| תזכורות תורים והפחתת הברזות | מערכת תורים קיימת (Calmark/Pink/Quicktor) | אחרי בחירת מערכת |
| סריקת הזדמנויות שבועית | משימה מתוזמנת של Claude | אישור של דוד |
| זרימות עסקיות כלליות | n8n | שרת קבוע או המחשב של דוד |

## זמין עכשיו
- `agent-browser` ו-Playwright: פעולות בדפדפן (באתרים שמותרים ברשת הסביבה).
- משימות מתוזמנות של Claude Code (בענן).

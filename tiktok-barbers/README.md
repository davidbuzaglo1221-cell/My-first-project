# סרטון TikTok – 10 טיפים לספרים: למה הלקוחות לא חוזרים

הסרטון המוכן: `tiktok_barbers_10_tips.mp4` (1080x1920, 30fps, אנכי, 1:17 דקות).

דוח הבדיקה של הקריינות בסרטון הסופי: `qa_report.txt` (בכל 12 הקטעים עבר, שגיאה כוללת 0.7%).

## מה יש בסרטון
- פתיח (hook) עם טיפוגרפיה קינטית, באמפר "20" זוהר, רייזר ואימפקט
- 10 סצנות, אחת לכל טיפ: מספר ענק מונפש, כרטיס כותרת, עמוד ספרים מונפש ומספריים
- מעבר (קאט) בין כל טיפ בפסי עמוד ספרים אדום-לבן-כחול, עם זום פאנץ' ו-whoosh
- כתוביות בסגנון TikTok, מילה אחרי מילה, עם הדגשה למילה שנאמרת עכשיו
- פס התקדמות "טיפ X/20" ותג מותג (BARBER TIPS)
- קריין עברי טבעי (Microsoft Avri neural, `tts_edge.py`) עם תזמון מדויק לכל מילה בכתוביות
- ביט מקורי שסונתז מאפס (לא מוזיקה מוגנת), עם דאקינג אוטומטי מתחת לקריין
- אפקטים קוליים: גזירת מספריים, פופ, whoosh, אימפקט ודינג
- עוצמה מנורמלת ל-‎-14 LUFS (התקן של TikTok)
- כל הטקסטים נשמרים בתוך אזורי הבטיחות של הממשק של TikTok

## איך משנים
- טקסטים וקריינות: `script.json`
- שם המותג: `BRAND` בתוך `render.py`

## איך בונים מחדש
```
python3 tts_edge.py              # he-IL-AvriNeural
python3 qa.py <ASR_DIR> build/voice_raw.wav build/timeline.json   # בדיקת שמיעה (ivrit-ai whisper)
python3 audio.py
./mix.sh
python3 render.py <FONT_DIR>     # Heebo + Rubik (מ-@fontsource), ממוזגים עברית+לטינית
# ואז concat של build/part_*.mp4 יחד עם build/mix.wav
```

# 20 טיפים לכושר · סרטון טיקטוק של 20 דקות

סרטון אנכי (1080×1920, 30fps) שנבנה כולו בקוד: גרפיקה בתנועה, כתוביות קריוקי בעברית, ופסקול מקורי שסונתז מאפס.

- `content.py`: התסריט המלא (20 טיפים, עצירות, פתיחה וסיום) וציר הזמן על רשת של 120 BPM.
- `render.py`: מנוע הגרפיקה. `python3 render.py still 41 frame.png` מרנדר פריים בודד.
- `audio.py`: הפסקול (קיק, קלאפ, 808, קאובל, פד) והאפקטים, מסונכרנים לאותו ציר זמן.
- `build.sh <תיקייה>`: מרנדר הכול ומחבר לקובץ mp4 אחד (בערך 25 דקות על 4 ליבות).
- `fonts/`: Heebo ו-Rubik (רישיון OFL), עם עברית ולטינית מאוחדות בקובץ אחד.

דרוש: Python 3 עם Pillow (עם libraqm), numpy, scipy, ו-ffmpeg.

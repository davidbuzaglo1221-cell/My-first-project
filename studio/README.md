# פריים — סטודיו וידאו

רעיון אחד בעברית → סרטון MP4 מוגמר, ב-9:16, 16:9 או 1:1.

## מה הוא עושה
1. **מנתח את הרעיון**: מטרה (לקוחות, צפיות, צחוק, ללמד, סיפור), טון, אורך.
2. **בונה תסריט וסצנות**: פתיחה בשנייה הראשונה, משפטים קצרים, קריאה לפעולה. המילים של דוד הן בריף ולא עולות על המסך.
3. **בוחר מנוע**: במצב אוטומטי — הכי מתאים מבין המנועים שיש להם מכסה חינמית. אם אין, המנוע המקומי (חינם תמיד).
4. **מייצר במקביל** בכמה מנועים, ו**משווה**: רזולוציה, אורך, ציון טכני, עלות, זמן הפקה. מסמן את "הכי טוב".
5. **עורך ומרכיב**: התאמת יחס מסך (עם רקע מטושטש כשצריך), כתוביות עבריות מונפשות, קריינות עברית, מוזיקה מהספרייה שלנו עם דאקינג מתחת לקול, עוצמה ‎-14 LUFS לרשתות.
6. **מייצא MP4** (H.264 + AAC, faststart) עם הורדה ישירה.

## המנועים
ראו `ENGINES.md` (דוח תאימות מלא עם מקורות).

| מנוע | מה הוא נותן | חינם |
|---|---|---|
| Vaideo | סרטון מוגמר עם קריינות **בעברית** | 5 סרטונים ב-API |
| AITuber | סרטון מוגמר עם תמונות AI וכתוביות | 100 קרדיטים (~3 סרטונים של 30 שנ׳) |
| Dreamina Seedance (BytePlus) | וידאו גנרטיבי אמיתי, קולנועי | בתשלום |
| Korpi | תכנון חינם; קליפים מ-Veo / Kling / Seedance | תכנון בלבד |
| מקומי | אנימציה מתוכנתת וטיפוגרפיה — **לא וידאו AI** | תמיד |

## חיסכון: חוקים שקוד אוכף
- כל מנוע מקבל החלטה: **חינם / בתשלום / לא זמין** (`lib/budget.mjs`).
- יצירה בתשלום **נחסמת בשרת** (תשובה 402) אלא אם הבקשה כוללת אישור לסכום שלפחות שווה להערכה. בממשק זה חלון אישור; בשורת הפקודה זה `--approve`. מחיר לא ידוע דורש אישור מפורש נפרד.
- מצב אוטומטי לא בוחר מנוע בתשלום אף פעם.
- קרדיטים שנקנו בתוכנית בתשלום נחשבים כסף.
- כל יצירה נרשמת ב-`data/history.json`; מצב לכל שירות ב-`data/ledger.json` (מחובר, קרדיטים שנותרו, מכסה חינמית, נוצל, איכות ואורך אחרונים).

## סודות
- מפתחות **לא נשמרים בקוד ולא ב-git**.
- בסשן הענן של Claude: המפתח נשמר כ"סוד רשת" — הפרוקסי מוסיף אותו לבקשה, והקוד לא רואה אותו בכלל.
- על מחשב: משתני סביבה (`VAIDEO_API_KEY`, `AITUBER_API_KEY`, `KORPI_MCP_TOKEN`, `ARK_API_KEY`) או `studio/.secrets.json` (מוחרג מ-git, הרשאות 600).

## הפעלה
```bash
cd studio
npm start            # ממשק: http://127.0.0.1:4747
npm run check        # בדיקת כל החיבורים + טבלת החיסכון
npm test             # 19 בדיקות יחידה ושרת
npm run e2e          # דפדפן אמיתי: רעיון → סרטון → הורדה, ושלושת יחסי המסך
node cli.mjs make "רעיון" --len 30 --aspect 9:16 --engines auto
```
דרישות: Node 20+, ffmpeg, Python 3 עם `edge-tts` (לקריינות).

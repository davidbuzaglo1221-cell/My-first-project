# ויראל סטודיו

רעיון אחד בעברית → סרטון ויראלי מוגמר (MP4, ‏9:16 / 1:1 / 16:9) לטיקטוק, רילס ושורטס:
פירות וירקות מדברים, חיות עם אישיות, דמויות תלת־ממד, דמויות ריאליסטיות, שיחות בין דמויות, טוויסטים.

## הצינור
1. **ניתוח**: מטרה (צחוק, סיפור, ללמד, לקוחות, צפיות), זיהוי דמויות מהרעיון (עגבנייה, חתול…), סגנון אוטומטי.
2. **תסריט**: פתיחה בשנייה הראשונה, התפתחות, טוויסט, פאנץ׳, קריאה לפעולה. דיאלוג כשיש שתי דמויות ומעלה.
3. **סצנות**: לכל סצנה דובר, שורה, כיתוב קצר, ופרומפט ויזואלי שכולל את תיאור כל הדמויות — אותו מראה בכל שוט.
4. **דמויות**: ספריית דמויות עם תמונת רפרנס, צבעים, פנים, אופי וקול. AITuber מקבל אותן כ-Elements; Seedance כתמונות רפרנס.
5. **הנפשה וקול**: מנוע AI לפי היכולת (וידאו, סנכרון שפתיים), קול נפרד לכל דמות.
6. **עריכה**: התאמת יחס מסך, כתוביות עבריות עם שם הדובר, מוזיקה מתחת לקול, עוצמה ‎-14 LUFS, MP4 עם faststart.
7. **אימות**: שום סרטון לא מוצג כמוכן לפני ש-ffprobe מאשר קובץ אמיתי עם וידאו ואורך.

## סגנונות
קולנוע ריאליסטי · קרטון תלת־ממד · אנימציה בהשראת פיקסאר · קומדיה ויראלית · דמויות היפר־ריאליסטיות · מיקס יצירתי.
אוטומטי לפי הרעיון; אפשר לשנות.

## מנועים
ראו `ENGINES.md` — טבלת יכולות מלאה עם מקורות ומצב החיבור.

## חיסכון
- כל מנוע מקבל החלטה: **חינם / בתשלום / לא זמין** (`lib/budget.mjs`).
- יצירה בתשלום נחסמת בשרת (402) עד אישור לסכום שלפחות שווה להערכה. מחיר לא ידוע דורש אישור נפרד.
- אוטומטי לא בוחר מנוע בתשלום אף פעם.
- יתרה מוצגת רק כשהשירות עצמו החזיר אותה. מכסה "לפי האתר" מסומנת כך.

## התקדמות והמשך
- כל שלב נשמר ב-`out/<job>/job.json`, כולל מזהי העבודה אצל השירות.
- יצירה שנקטעה (הפעלה מחדש של השרת) מסומנת "נקטע" ואפשר להמשיך אותה. עבודה שכבר נשלחה לשירות נבדקת שוב — לא נוצרת ולא משולמת פעמיים.

## סודות
- מפתחות לא נשמרים בקוד ולא ב-git.
- בסשן הענן: "סוד רשת" — הפרוקסי מוסיף את המפתח, והקוד לא רואה אותו.
- על מחשב: משתני סביבה (`AITUBER_API_KEY`, `VAIDEO_API_KEY`, `KORPI_MCP_TOKEN`, `ARK_API_KEY`) או `studio/.secrets.json` (מוחרג מ-git).

## הפעלה
```bash
cd studio
npm start            # ממשק: http://127.0.0.1:4747
npm run check        # בדיקת כל החיבורים מול השירותים
npm test             # 28 בדיקות
npm run e2e          # דפדפן אמיתי: דמויות → רעיון → סרטון → הורדה + שלושת יחסי המסך
node cli.mjs make "רעיון" --len 30 --aspect 9:16 --engines auto
```
דרישות: Node 20+, ffmpeg, Python 3 עם `edge-tts`.
דמויות הבדיקה ב-`test/fixtures` צוירו בקוד (SVG) לבדיקות בלבד.

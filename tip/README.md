# טיפ בקלות

מחשבון טיפ למסעדה, בעברית ובלי התקנה.

- בוחרים את אחוז הטיפ לפי איכות השירות (10%, 12%, 15%, 18%, או כל אחוז בין 0 ל-30).
- מחלקים את החשבון בין כמה סועדים.
- מעגלים את הטיפ לשקל שלם, או את הסכום של כל סועד.
- רואים בדיוק אילו שטרות ומטבעות להשאיר אם משלמים את הטיפ במזומן.
- מסך גדול להראות למלצר, וכפתור להעתקת הסיכום לקבוצה בוואטסאפ.
- תומך בשקל, דולר ויורו.

## איך פותחים

- פשוט פותחים את `index.html` בדפדפן (אין צורך בשרת).
- `app.html` הוא אותו הדף בלי עטיפת ה-HTML, והוא הגרסה שמפורסמת כ-artifact ב-Claude.
  אחרי שינוי ב-`app.html` בונים מחדש את `index.html` עם `./build.sh`.

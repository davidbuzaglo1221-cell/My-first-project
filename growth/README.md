# צמיחה

אפליקציית התפתחות אישית בעברית שלומדים בה באוזניים: 8 נושאים ו-24 פרקים בשיחה בין שני מגישים עם שאלה בסוף כל פרק, מעבדת פנים (זיהוי הבעות ומיקרו-הבעות), נשימה מודרכת, מחשבון ריבית ודמי ניהול, מאמן AI עם תרגול שיחות, משימות יומיות, רמות ורצף ימים.

- האפליקציה: https://claude.ai/artifact/TjG8wHdJZuNTFesKMg6iei
- תוכן הפרקים והמשימות: `content.js`. המסך והלוגיקה: `app.src.html`.
- בנייה: `node build.mjs` (יוצר `dist/app.html`). בדיקה: `node e2e.cjs`.

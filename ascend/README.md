# ASCEND

מערכת אישית לשיפור עצמי בעברית: יומן יומי, תוכנית של 10, 20 או 30 דקות, אימון בששה מסלולים, סימולטורים למכירות ולזוגיות, בונה הצעות, מאמן, ומעקב שמחושב מהנתונים שלך בלבד.

## הרצה מקומית

```bash
cd ascend
npm install
npm run dev        # http://localhost:5173
```

בדיקות:

```bash
npm run check      # בדיקת טיפוסים + בדיקות יחידה (51)
npm run build      # בנייה לפרודקשן
npm run preview    # http://localhost:4173
npm run e2e        # מסע משתמש מלא בדפדפן ב-390px (דורש שהשרת רץ, ו-playwright זמין)
```

## מה עובד היום (נבדק)

- **הגדרה ראשונית**: שם, עד שלוש מטרות, זמן יומי, יעד שינה, מצב מקצועי, ניסיון במכירות. יש ולידציה והנתונים נשמרים.
- **בית**: ברכה לפי השעה, שלוש משימות יומיות שמתאימות למטרות ולזמן (גוף, מחשבה, עבודה), סימון השלמה שנשמר אחרי רענון, סיכום צ'ק-אין, רצף נוכחי והרצף הארוך ביותר שחושבו מהרישומים, קיצורים, ורפלקציה יומית.
- **צ'ק-אין**: שעות שינה, איכות שינה, אנרגיה, לחץ, מצב רוח, פעילות גופנית, דקות למידה, משקל אופציונלי, והרגלים. אפשר לערוך רישום מ-30 הימים האחרונים.
- **אימון**: ששת המסלולים (A עד F), ספרייה עם חיפוש, שמירה, סימון השלמה, הערות אישיות, "המשך מאיפה שעצרת", וייצוא כל שיעור לקובץ Markdown.
- **השמעה קולית**: השמעת השיעור בדפדפן (קול בעברית אם מותקן במכשיר), עם השהיה, קודם, הבא ועצירה.
- **סימולטור מכירות**: שלושה תרחישים, שלוש רמות. הלקוח מעלה התנגדויות, ואתה עונה במילים שלך. בסוף יש משוב לפי שבעה היבטים, והסבר ודוגמה לכל תגובה חלשה. תגובה שחוזרת על עצמה נענשת.
- **סימולטור זוגיות**: שלושה תרחישים עם בחירת תגובה. המשוב מפריד בין מה שנצפה לבין מה שמניחים.
- **בונה הצעות**: מחמישה שדות נוצרת טיוטה: הצעה, ערך, פרופיל לקוח, מסרים, רעיונות תוכן, תוכנית רכישה של ארבעה שבועות וניסוי לבדיקת ביקוש. אין בה תחזית הכנסה.
- **מאמן**: שיחה עם שבעה נושאי התחלה מהירה. במצב בסיסי המאמן שואל שאלה מדויקת, מפריד עובדות מהנחות, מציג עיקרון, מציע שני צעדים, ומבקש לבחור צעד אחד.
- **מעקב**: גרפים מנתוני צ'ק-אין בלבד (נקודות חסרות נשארות חסרות, בלי השלמה), פעילות גופנית, שעות שינה, משקל, הרגלים עם אחוזי השלמה ל-7 ו-30 ימים, היסטוריית צ'ק-אין, וסקירות שבועיות.
- **פרופיל**: עריכה, ייצוא גיבוי JSON, שחזור מגיבוי (עם בדיקה שהקובץ תקין), ומחיקת כל הנתונים עם אישור כפול.
- **שמירה**: הכול נשמר ב-localStorage בדפדפן. נתונים פגומים או ישנים מנוקים בלי לקרוס.

## הגדרת מאמן מבוסס מודל שפה (אופציונלי)

האפליקציה עובדת בלי זה. כדי להפעיל תשובות AI:

| משתנה | חובה | תפקיד |
|---|---|---|
| `ANTHROPIC_API_KEY` | כן, להפעלת AI | המפתח נשאר בשרת. לא נשלח לדפדפן. |
| `ASCEND_ACCESS_TOKEN` | מומלץ בפרודקשן | מונע שימוש זר במפתח שלך. הדפדפן צריך לשלוח אותו (ראה מסך הפרופיל). |
| `ASCEND_COACH_MODEL` | לא | ברירת מחדל: `claude-sonnet-5-5` |

ב-Vercel: מגדירים את הערכים בהגדרות הפרויקט, ומגדירים Root Directory ל-`ascend`. נקודת הקצה היא `api/coach.js`.

הטוקן נשלח מהדפדפן בכותרת `x-ascend-token`, והוא נשמר במסך הפרופיל ("קוד גישה למאמן"). הוא לא נכלל בייצוא הנתונים.

## מגבלות ידועות

- **אין חשבון וסנכרון בין מכשירים.** הנתונים נשארים בדפדפן. כדי לעבור מכשיר, משתמשים בייצוא ובשחזור.
- **חיבור ל-NotebookLM לא בוצע.** ל-NotebookLM אין API ציבורי, כך שאין דרך אוטומטית להזין אליו תוכן. במקום זאת כל שיעור יוצא לקובץ Markdown שאפשר להעלות אליו כמקור.
- **"פודקאסט" אינו קובץ שמע.** ההשמעה היא קריאה בזמן אמת בעזרת קול הדפדפן. אין יצירה של קובץ MP3.
- **סימולטורים מבוססי כללים.** הציון נקבע לפי מילות מפתח ומבנה תגובה, לא לפי הבנה. זה מספיק לתרגול ולמשוב כללי, אבל לא מחליף תגובה של אדם.
- **תוכן השיעורים מוגבל.** יש שבעה שיעורים: מסלול B עם שניים, ומסלולים A, C, D, E ו-F עם שיעור אחד כל אחד. המסלולים הם הצעד הבא בתוכן.
- **לא צוטטו מחקרים ספציפיים.** כל שיעור מסומן ברמת ראיות והערה שהתוכן כללי. לא נבדקו מקורות בפועל, ולכן לא נוספו קישורים, מספרים או מאמרים. אפשר להוסיף מקורות מאומתים בקובץ `src/content/lessons.ts`.
- **שאלון "סגנון למידה" לא נכלל בהגדרה הראשונית.**
- **בדיקה נעשתה בכרום בלבד** בגודל מסך של iPhone (390px). לא נבדקה ב-Safari אמיתי. ב-iPhone, הקול העברי בהשמעה תלוי בקולות המותקנים במכשיר.
- **התקנה ל-iPhone לא נבדקה.** יש manifest, service worker בסיסי ואייקון SVG. צריך לבדוק ב-Safari אמיתי.

## מבנה התיקייה

```
src/
  content/   שיעורים, תרחישים, קטלוג משימות (כאן מוסיפים תוכן)
  lib/       לוגיקה טהורה: תכנון יומי, רצפים, סימולטור, מאמן, ייצוא, אחסון
  screens/   מסכים
  components/ רכיבי UI משותפים
  styles/    עיצוב ו-tokens
api/coach.js נקודת קצה לשרת (Vercel) או לפיתוח מקומי
e2e/journey.cjs מסע משתמש בדפדפן
```

## הצעד הבא הכי שימושי

להשלים את מסלולים A ו-C עד F בשיעורים נוספים, ולהוסיף לכל שיעור מקורות שנבדקו בפועל. במקביל, לבדוק קריאה אמיתית ל-API עם מפתח, ולבדוק את ההתקנה ב-Safari.

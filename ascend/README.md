# ASCEND

אוניברסיטה פרטית בכיס: שיעורי אודיו קצרים בעברית על הספרים החשובים בעולם בתחומי כסף, שכנוע, פסיכולוגיה, תקשורת, ביטחון, משמעת, יזמות, מנהיגות ומיינדסט. כל שיעור מסתיים בתרגיל מעשי, הרגל למעקב ושאלה ליומן.

- **תוכן:** 28 ספרים, 60 שיעורים מקוריים, 7 מסלולי למידה ומסלול אישי שנבנה מההערכה העצמית. השיעורים הם הסברים מקוריים של הרעיונות, לא קריינות או תרגום של הספרים (`src/content/books`).
- **אודיו:** קריינות בקול העברי של המכשיר, משפט אחר משפט, עם הפעלה, השהיה, ±15 שניות, מהירות, טיימר שינה, המשך מאותה נקודה ושליטה ממסך הנעילה. אם לשיעור יש `audioUrl` (קובץ מורשה או מוקלט), הוא מתנגן במקום. אפשר להוסיף קבצי אודיו שבבעלותך בספרייה, תחת "האודיו שלי".
- **נתונים:** הכל נשמר במכשיר (localStorage, וקבצי אודיו ב־IndexedDB). גיבוי ושחזור בהגדרות.

## פיתוח

```bash
npm install
npm run dev           # http://localhost:5173
npm test              # בדיקות תוכן ופילוח משפטים
npm run build         # PWA ל־dist/
npm run build:single  # קובץ אחד, dist-single/ascend.html
```

## קול טבעי יותר

איכות הקריינות תלויה בקול שמותקן במכשיר. ב־iPhone: הגדרות, נגישות, תוכן מוקרא, קולות, עברית, ולהוריד את הגרסה המשופרת. ב־Android: נתוני קול בעברית של Google. לקריינות אחידה באיכות אולפן, אפשר להפיק קובצי MP3 מכל שירות TTS מורשה ולהוסיף `audioUrl` לכל שיעור.
